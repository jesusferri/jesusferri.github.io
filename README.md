# Web SEO de Jesús Ferri
1. Crea en GitHub un repositorio público llamado TU-USUARIO.github.io y sube todos estos archivos.
2. En Settings > Pages, elige "Deploy from a branch" > main > / (root).
3. Cambia `url` en _config.yml por tu dirección real.
4. Rellena la página "Mi trabajo" con tus datos reales.
5. Añade entradas al blog creando archivos en _posts con el formato AAAA-MM-DD-titulo.md
